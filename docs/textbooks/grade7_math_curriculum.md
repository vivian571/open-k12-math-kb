## 二、学习路径与知识图谱拓扑依赖

```
[有理数概念与数轴] ➔ [有理数四则混合运算] ➔ [用字母表示数与代数式]
                                                  │
                                                  ▼
[实际应用模型]  [一元一次方程解法五步曲]  [整式的加减与去括号]
```

1. **第一阶段：数系的扩充与符号法则**
   - 突破负号心理障碍，掌握数轴的几何直观，牢记绝对值的非负性 $|a| \ge 0$。
2. **第二阶段：从算术到代数**
   - 字母表示数，理解同类项两要素（字母相同、指数相同），去括号法则严格防漏变号。
3. **第三阶段：建模与方程思想**
   - 掌握去分母防漏乘常数项，解方程五步曲程序化演算；把实际生活文字转化为代数守恒关系。
